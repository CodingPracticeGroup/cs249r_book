# Volume I Chinese Translation (简体中文)

## Translation Convention (翻译约定)

- **Prose**: Translate to Simplified Chinese (简体中文)
- **Technical terms**: Keep in English (e.g., `pipeline`, `inference`, `quantization`, `backpropagation`)
- **Named callouts**: Keep in English (`Principle`, `Theorem`, `War Story`, `Napkin Math`, `Lighthouse`, `Systems Perspective`, `Checkpoint`)
- **Code/commands**: Keep in English as-is
- **Equation references**: Use Chinese prefix (图, 表, 公式, 代码)
